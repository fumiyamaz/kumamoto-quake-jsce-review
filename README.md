# 平成28年熊本地震 — 土木学会全国大会論文からの振り返り

土木学会全国大会（年次学術講演会）の論文から、平成28年（2016年）熊本地震を扱った論文を抽出し、
年次・部門・テーマの推移と、論文本文から読み取れる実務上の示唆を1ページにまとめたレポートです。

**公開ページ: https://fumiyamaz.github.io/kumamoto-quake-jsce-review/**

## 構成

`index.html` の1ファイルで完結しています。外部のCSS・JS・フォント・画像を読み込みません。
タブで3つのビューを切り替えます。

| タブ | 内容 |
|---|---|
| 01 論文一覧 | 抽出した論文の一覧。タイトル・著者・所属・キーワードの横断検索と、年・部門・テーマでの絞り込み |
| 02 概要情報 | 年次ごと・部門別・テーマ別の3つの比較 |
| 03 応急対応・復旧復興への示唆 | 被害の読み方と、発災直後から10年後までの時間軸に沿った実務示唆 |

`#papers` / `#overview` / `#insights` のハッシュで各タブに直接リンクできます。

## このリポジトリの位置づけ

`index.html` は生成物です。生成元のパイプラインとテンプレートは別リポジトリ（JSCE論文データレイク）の
`src/kumamoto_quake/` にあり、以下の4ステップで作られます。

```
extract_corpus    統合DBから熊本地震関連論文を抽出
analyze_corpus    年次・部門・テーマ・キーワード・機関を集計
extract_findings  論文本文から結論・考察に相当する記述を抽出
build_report      テンプレート4枚を結合して index.html を生成
```

更新する場合は、生成側で `build_report` を実行し、出力された HTML を `index.html` として
このリポジトリに置き換えてコミットします。

## 収録しないもの

論文の原本PDFはこのリポジトリに含めません（`.gitignore` で `pdf/` を除外しています）。
本文中の論文IDは土木学会のサイト上の原本PDFへリンクします。
